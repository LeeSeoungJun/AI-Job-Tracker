# AI Job Tracker

채용공고를 수집하고, 웹 대시보드에서 지원 상태와 메모를 관리하는 Python 프로젝트입니다.

사람인·잡코리아에서 공고를 수집하고 SQLite에 저장하며, Streamlit으로 화면을 제공합니다.

## 1. 설치 및 실행 방법

### 프로젝트 다운로드

```bash
git clone https://github.com/LeeSeoungJun/AI-Job-Tracker.git
cd AI-Job-Tracker
```

### 필요한 라이브러리 설치

Python이 설치된 환경에서 다음 명령을 실행합니다.

```bash
python -m pip install -r requirements.txt
```

### 채용공고 수집

```bash
python main.py
```

기본 검색어는 **데이터분석**, 수집 범위는 플랫폼별 **1페이지**입니다.

검색어와 페이지 수는 `main.py` 하단에서 변경할 수 있습니다.

```python
if __name__ == "__main__":
    run_pipeline(keyword="데이터분석", pages=1)
```

수집한 공고는 프로젝트 폴더의 `jobs_data.db`에 저장됩니다. DB는 처음 실행할 때 자동으로 생성됩니다.

### 대시보드 실행

Windows에서는 **`공고보기.bat`를 더블클릭**합니다.

명령어로 실행할 수도 있습니다.

```bash
python launch.py
```

브라우저가 자동으로 열리며 대시보드가 표시됩니다. 종료하려면 실행 창에서 `Ctrl+C`를 누릅니다.

대시보드는 저장된 공고를 보여줍니다. 새 공고를 가져오려면 `python main.py`를 다시 실행해야 합니다.

## 2. 사용 방법

- 기업명과 공고 제목으로 검색할 수 있습니다.
- 지원 상태·즐겨찾기·마감일로 공고를 필터링할 수 있습니다.
- 공고를 카드 또는 표로 확인할 수 있습니다.
- 원문 링크에서 실제 채용공고를 확인할 수 있습니다.
- 지원 상태를 **미지원 / 지원 예정 / 지원 완료**로 관리할 수 있습니다.
- 공고별 메모를 작성하고 저장할 수 있습니다.
- 수집된 주요 업무·자격요건·우대사항을 확인할 수 있습니다.

지원 상태를 직접 변경한 공고는 기본 목록에서 숨겨집니다. 지원 상태 필터를 선택하거나 **상태 변경한 공고도 보기**를 켜면 다시 확인할 수 있습니다.

## 3. 수집 및 정리 기준

- 서울·경기·인천 근무지의 공고만 수집·표시합니다.
- 신입·경력무관 또는 표기된 경력이 2년 이내인 공고를 대상으로 합니다.
- 목록에서 석사·박사 필수로 표시된 공고와 이미 마감된 공고는 새로 저장하지 않습니다.
- 회사명·공고 제목·근무지가 같은 다른 플랫폼 공고는 중복 저장을 방지합니다.
- 수집 실행 시 마감일이 지난 기존 공고를 정리하며, 삭제 전에 전체 DB를 `backups/`에 백업합니다.

**마감 공고를 삭제하면 해당 공고의 메모·지원 상태·즐겨찾기도 함께 삭제됩니다.** 오늘 마감인 공고나 마감일을 확실하게 판단할 수 없는 공고는 유지합니다.

## 4. 파일 및 폴더 설명

### 실행 및 화면

| 파일 | 설명 |
| --- | --- |
| `main.py` | 공고 수집의 시작점입니다. 마감 공고 정리, 플랫폼별 수집, 조건 필터링, 중복 확인, 상세 수집과 DB 저장을 실행합니다. |
| `app.py` | Streamlit 대시보드입니다. 공고 조회, 검색, 필터, 지원 상태 변경, 메모 저장 등의 화면을 제공합니다. |
| `launch.py` | 대시보드 서버를 실행하고, 준비되면 브라우저를 자동으로 엽니다. |
| `공고보기.bat` | Windows에서 더블클릭으로 `launch.py`를 실행하는 파일입니다. |

### 공고 수집 — `crawler/`

| 파일 | 설명 |
| --- | --- |
| `base.py` | 수집기가 공통으로 사용하는 기본 구조와 실행 흐름을 정의합니다. |
| `saramin.py` | 사람인의 공고 목록과 상세 내용을 수집합니다. |
| `jobkorea.py` | 잡코리아의 공고 목록과 상세 내용을 수집합니다. |
| `sections.py` | 상세 본문을 주요 업무, 자격요건, 우대사항 등으로 나눕니다. |

### 데이터 저장 — `database/`

| 파일 | 설명 |
| --- | --- |
| `models.py` | 채용공고 테이블의 항목과 자료형을 정의합니다. |
| `connection.py` | SQLite 연결, 테이블 초기화, 기존 DB에 필요한 열 추가, 공고 저장과 갱신을 담당합니다. |
| `cleanup.py` | 마감된 공고를 찾아 DB를 백업한 뒤 삭제합니다. |

### 공통 처리

| 파일 | 설명 |
| --- | --- |
| `job_identity.py` | 회사명·제목·근무지를 비교해 플랫폼 간 중복 공고를 판별합니다. |
| `job_policy.py` | 경력·학력 조건과 마감 여부를 판단합니다. |
| `job_view.py` | 날짜 표시, 마감일 필터, 지역 판별, 송도 센트럴파크 기준 거리 계산 등 화면에서 사용하는 처리를 담당합니다. |
| `requirements.txt` | 실행에 필요한 Python 라이브러리를 정리한 파일입니다. |
| `.gitignore` | DB, 백업, 임시 자료 등 GitHub에 올리지 않을 파일을 지정합니다. |
| `README.md` | 설치·실행 방법과 프로젝트 구성을 안내합니다. |

### 테스트 — `tests/`

| 파일 | 설명 |
| --- | --- |
| `test_cleanup.py` | 마감 공고 삭제, 백업, 날짜·학력 조건을 검증합니다. |
| `test_details.py` | 상세 본문 추출과 수집 실패 시 처리를 검증합니다. |
| `test_job_view.py` | 날짜·지역·거리·경력 조건과 기존 DB 변경 처리를 검증합니다. |
| `test_jobkorea.py` | 잡코리아 목록 분석, 접속 제한 감지, 플랫폼 간 중복 처리를 검증합니다. |
| `test_regressions.py` | 공고 저장, 중복 처리, 지원 상태 변경, 메모 저장 등 주요 기능을 검증합니다. |

테스트는 다음 명령으로 실행합니다.

```bash
python -m unittest discover -s tests -v
```

## 5. 로컬에서 생성되는 파일

다음 파일과 폴더는 GitHub에 포함하지 않습니다.

| 항목 | 용도 |
| --- | --- |
| `jobs_data.db` | 수집한 공고, 개인 메모, 지원 상태 등을 저장하는 DB |
| `backups/` | 마감 공고 삭제 전에 생성하는 DB 백업 |
| `work/` | 임시 수집 자료와 작업 파일 |
| `__pycache__/` | Python이 자동 생성하는 캐시 |
| `.venv/`, `venv/` | 로컬 Python 가상환경 |
| `.env`, `.streamlit/secrets.toml` | 비밀 설정을 보관하는 파일 |

## 6. 참고 사항

- 잡코리아는 접속 제한이 발생할 수 있으며, 실제 목록·상세 수집 검증이 완료되지 않았습니다.
- 사이트 구조가 변경되면 수집 코드 수정이 필요할 수 있습니다.
- 이미지로 작성된 공고의 글자 인식(OCR)은 지원하지 않습니다.
- 기본 거리 정렬은 송도 센트럴파크에서 구·시의 대략적인 중심까지의 직선거리 기준입니다.
- 실제 접수 가능 여부와 상세 지원 조건은 채용공고 원문에서 확인하세요.
