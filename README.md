# [개인] 채용공고 수집 및 지원 관리 대시보드

Windows에서는 **공고보기.bat**를 더블클릭하면 브라우저가 열립니다.
실행 창을 유지한 채 이용하고, 종료할 때는 그 창에서 Ctrl+C를 누르세요.
바탕화면에 바로 가기를 만들어도 됩니다. 실행 파일 자체는 프로젝트 폴더에 두세요.

## 화면 사용

- 카드의 **원문 보기**로 채용 페이지를 엽니다.
- **지원 상태 · 즐겨찾기 · 메모 수정**을 펼쳐 수정한 뒤 **저장하기**를 누릅니다.
- 왼쪽에서 기업·제목 검색, 지원 상태, 즐겨찾기, 마감일 필터를 조합합니다.
- 마감 임박순 정렬, 표 보기, 페이지 이동을 지원합니다. 카드 한 페이지는 12개입니다.
- 연도가 없는 날짜는 수집일에 가장 가까운 연도로 추정합니다. 상시·채용 시 마감 공고는 날짜 미정으로 분류합니다. 실제 접수 여부는 원문에서 확인하세요.

## 설치 및 수집

Python 설치 후 처음 한 번 실행:

```powershell
python -m pip install -r requirements.txt
```

새 공고 수집은 기존과 같이 `python main.py`로 실행합니다.
현재 기본 검색어는 데이터분석, 수집 범위는 1페이지입니다.
`main.py` 실행 시 한국 날짜를 기준으로 어제까지 마감된 기존 공고를 자동 삭제합니다.
메모·즐겨찾기·지원 상태도 함께 삭제되며, 삭제 전 전체 DB가 `backups` 폴더에 보관됩니다.
오늘 마감, 상시, 날짜 미정, 잘못된 날짜, 연도 추정이 불확실한 과거 공고는 유지합니다.
새로 수집한 공고 중 이미 마감일이 지난 공고와 목록 학력이 석사·박사 필수인 공고는 저장하지 않습니다.
대졸 이상·학력무관·석박사 우대는 유지하며, 상세 본문의 학력 조건까지 검사하지는 않습니다.
기존에 저장된 석사·박사 공고는 학력만을 이유로 삭제하지 않습니다.
화면은 저장된 공고를 표시하며 자동으로 새 공고를 수집하지 않습니다.

## 상세 본문 자동 수집

`python main.py` 실행 시 목록에서 학력·마감 조건을 적용한 뒤, 남은 공고의 상세 페이지도 읽습니다.
기존 공고도 이번 검색 결과에 포함되면 자동 수집 내용이 갱신됩니다. 기존 DB 전체를 일괄 재수집하지는 않습니다.
카드의 **공고 내용 · 자동 수집**을 펼치면 주요 업무, 자격요건, 우대사항과 전체 본문을 확인할 수 있습니다.
제목을 기준으로 텍스트를 분리하므로 형식이 다른 공고는 전체 본문에서 확인해야 합니다.
이미지 글자 인식(OCR)은 포함하지 않았습니다. 이미지 공고와 접근 실패는 수집 상태에 표시합니다.
직접 작성한 우대사항 메모·개인 메모·지원 상태·즐겨찾기는 재수집해도 보존됩니다.
상세 요청이 실패하면 이전 본문을 유지하고 최근 실패 상태를 표시합니다.
공고마다 추가 요청을 하므로 목록만 수집할 때보다 시간이 더 걸립니다.

기존 jobs_data.db의 공고와 메모는 유지하고, 처음 실행할 때 지원 상태와 즐겨찾기 열만 추가합니다.
지원 상태 기본값은 미정입니다. 기존 메모에서 지원 상태를 자동 추론하지 않습니다.
