# [개인] 채용공고 수집 및 지원 관리 대시보드

Windows에서는 **공고보기.bat**를 더블클릭하면 브라우저가 열립니다.
실행 창을 유지한 채 이용하고, 종료할 때는 그 창에서 Ctrl+C를 누르세요.
바탕화면에 바로 가기를 만들어도 됩니다. 실행 파일 자체는 프로젝트 폴더에 두세요.

기존 공고와 새 수집 공고 모두 인천·서울·경기 근무지만 표시·수집합니다. 그 외 지역과 근무지 미정은 제외합니다.
기본 정렬은 송도 센트럴파크에서 구·시의 대략적인 중심까지 직선거리순입니다. 실제 사업장 거리나 출퇴근 시간과 다릅니다. 여러 근무지는 가장 가까운 곳을 기준으로 하며, 거리 미정은 마지막에 표시합니다. 최근 수집순·마감 임박순도 선택할 수 있습니다.
기존의 제외된 공고와 메모는 DB에 보존됩니다.

## 화면 사용

- 카드의 **원문 보기**로 채용 페이지를 엽니다.
- 카드의 **미지원·지원예정·지원완료** 버튼을 누르면 바로 상태가 저장됩니다. 메모 입력 폼은 표시하지 않으며 기존 메모는 보관합니다.
- 왼쪽에서 기업·제목 검색, 지원 상태, 즐겨찾기, 마감일 필터를 조합합니다.
- 마감 임박순 정렬, 표 보기, 페이지 이동을 지원합니다. 카드 한 페이지는 12개입니다.
- 연도가 없는 날짜는 수집일에 가장 가까운 연도로 추정합니다. 상시·채용 시 마감 공고는 날짜 미정으로 분류합니다. 실제 접수 여부는 원문에서 확인하세요.

## 설치 및 수집

Python 설치 후 처음 한 번 실행:

```powershell
python -m pip install -r requirements.txt
```

새 공고 수집은 기존과 같이 `python main.py`로 실행합니다.
현재 기본 검색어는 데이터분석, 수집 범위는 1페이지입니다.
`main.py` 실행 시 한국 날짜를 기준으로 어제까지 마감된 기존 공고를 자동 삭제합니다.
메모·즐겨찾기·지원 상태도 함께 삭제되며, 삭제 전 전체 DB가 `backups` 폴더에 보관됩니다.
오늘 마감, 상시, 날짜 미정, 잘못된 날짜, 연도 추정이 불확실한 과거 공고는 유지합니다.
새로 수집한 공고 중 이미 마감일이 지난 공고와 목록 학력이 석사·박사 필수인 공고는 저장하지 않습니다.
대졸 이상·학력무관·석박사 우대는 유지하며, 상세 본문의 학력 조건까지 검사하지는 않습니다.
기존에 저장된 석사·박사 공고는 학력만을 이유로 삭제하지 않습니다.
화면은 저장된 공고를 표시하며 자동으로 새 공고를 수집하지 않습니다.

## 상세 본문 자동 수집

`python main.py` 실행 시 목록에서 학력·마감 조건을 적용한 뒤, 남은 공고의 상세 페이지도 읽습니다.
기존 공고도 이번 검색 결과에 포함되면 자동 수집 내용이 갱신됩니다. 기존 DB 전체를 일괄 재수집하지는 않습니다.
카드의 **공고 내용 · 자동 수집**을 펼치면 주요 업무, 자격요건, 우대사항과 전체 본문을 확인할 수 있습니다.
제목을 기준으로 텍스트를 분리하므로 형식이 다른 공고는 전체 본문에서 확인해야 합니다.
이미지 글자 인식(OCR)은 포함하지 않았습니다. 이미지 공고와 접근 실패는 수집 상태에 표시합니다.
직접 작성한 우대사항 메모·개인 메모·지원 상태·즐겨찾기는 재수집해도 보존됩니다.
상세 요청이 실패하면 이전 본문을 유지하고 최근 실패 상태를 표시합니다.
공고마다 추가 요청을 하므로 목록만 수집할 때보다 시간이 더 걸립니다.

기존 jobs_data.db의 공고와 메모는 유지하고, 처음 실행할 때 지원 상태와 즐겨찾기 열만 추가합니다.
지원 상태 기본값은 미지원입니다. 기존 메모에서 지원 상태를 자동 추론하지 않습니다.

## 잡플래닛 평점

카드의 **잡플래닛 회사 찾아보기**는 회사명으로 잡플래닛 기업 페이지를 Google에서 검색합니다. 동일한 회사인지 확인한 뒤 **잡플래닛 평점 입력**에서 평점(5점 만점), 리뷰 수(선택), 확인 날짜를 저장하세요. 평점은 직접 입력한 값이며 공고별로 저장됩니다. 평점 저장 체크를 해제하고 저장하면 기록이 지워집니다. 재수집해도 입력한 기록은 유지됩니다.

2026-10-12에 기존 수도권 공고 25건(21개 회사)의 평점·리뷰 수를 공개 검색 결과에서 확인해 일괄 저장했습니다. 출처 링크와 공개 검색 확인 표시가 있으며, 검색 캐시 값이라 최신 화면과 다를 수 있습니다. 동명이인·미확인 회사 9곳은 제외했습니다. 이번 저장은 일회성이며 main.py 실행 시 잡플래닛 평점을 자동 갱신하지 않습니다.



지원 상태는 **미지원·지원 예정·지원 완료** 세 가지입니다. 새 공고는 미지원으로 표시되고, 상태를 직접 저장한 공고는 메인에서 숨깁니다. 상태 변경한 공고도 보기를 켜면 다시 확인할 수 있습니다. 기존 미정은 미지원, 관심은 지원 예정, 합격·불합격은 지원 완료로 통합하며 기존 숨김 여부는 유지합니다.

경력 조건은 신입·경력무관 또는 경력 표기가 2년 이내인 공고만 표시·수집합니다. 범위의 상한이 2년을 넘는 2~5년·1~7년 공고는 제외합니다. 1년↑·2년↑은 포함하고, 3년 이상 표기 또는 경력 조건 미정은 제외합니다. 기존 제외 공고는 삭제하지 않습니다.

평점 출처가 저장된 공고의 **잡플래닛 평점 보기** 버튼은 해당 기업 리뷰 페이지로 바로 연결합니다. 출처가 없는 공고는 잡플래닛 내부의 기업 검색으로 연결합니다.

잡플래닛 평점 수동 입력 폼은 제거했습니다. 카드 하단 **메모**에 간단히 적고 **메모 저장**을 누르면 저장됩니다. 메모 저장은 지원 상태를 바꾸거나 공고를 숨기지 않습니다. 기존 평점·출처 표시와 상태 버튼은 유지됩니다.

왼쪽 지원 상태 필터를 선택하면 해당 상태의 숨긴 공고도 표시합니다. 별도로 상태 변경한 공고도 보기를 켤 필요가 없습니다. 선택을 비우면 기본 메인 목록으로 돌아갑니다.

## 잡코리아 수집

main.py는 사람인과 잡코리아를 같은 검색어로 각각 수집합니다. 회사명(주식회사 표기 제외)·제목·근무지가 공백과 기호를 제외하고 모두 일치하는 다른 플랫폼 공고는 저장하지 않습니다. 제목이 다른 공고는 별도 채용일 수 있어 유지합니다. 기존 공고의 메모·지원 상태는 보존합니다.

잡코리아가 보안 정책으로 접속을 제한하거나 목록 구조가 달라지면 경고를 출력하고 사람인 수집은 계속합니다. 현재 환경에서 잡코리아 접속 제한이 확인되어 실제 목록·상세 수집 검증은 완료하지 못했습니다. 접속이 허용된 환경에서 추가 확인이 필요합니다.

## 저장소에 포함하지 않는 파일

개인 지원 기록과 메모가 담긴 DB, 백업, 임시 수집 자료(`work/`), 가상환경, 캐시, 비밀 설정은 Git에 올리지 않습니다. 새 환경에서는 DB가 자동 생성되며, `python main.py`로 공고를 수집할 수 있습니다.
